Kubernetes DockerHub Image Policy Webhook

This webhook validates container images in Kubernetes resources and only allows those from DockerHub repositories.

The webhook is running and listening for admission requests from the Kubernetes API server.

Webhook Endpoints

  • /webhook - Main webhook endpoint that validates images
  • /stats - Returns statistics about webhook operations
  • /health - Health check endpoint
  • /logs - View recent webhook logs

How it Works

This webhook validates that all container images used in Kubernetes resources come from DockerHub. It rejects resources that use images from other registries.

Supported Resources

The webhook validates images in the following Kubernetes resource types:

  • Pods
  • Deployments
  • StatefulSets
  • DaemonSets
  • ReplicaSets
  • Jobs
  • CronJobs
